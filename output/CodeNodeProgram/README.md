# CreateDesktopFolder

Java 21 program generated from CodeNode request `node-1783956448004`.

Compile and package steps are handled by CodeNode. Running the JAR creates one folder directly under the current user's Desktop.

```powershell
java -jar .\CreateDesktopFolder.jar
java -jar .\CreateDesktopFolder.jar MyFolder
```

The program is generated and compiled, but is not run automatically because the request requires confirmation before changing the Desktop.
