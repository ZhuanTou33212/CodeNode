# 独立源码优先人工抽检 v1

状态：30 题准备完成，真实人工标签尚未填写。关联 `rag-regression-v3`；本包抽取自已曝光 100 题，不能作为未见验收准确率。

## 抽样与盲审

- 单文件、跨文件、负样本各 10 题。按题集 SHA256 + 固定 salt 哈希排序抽样，不读取模型成败挑题。
- 打开 `review.html`。页面显示中性题号、问题、来源片段与完整冻结源码；不显示作者标签、模型答案或成绩。
- 请由没有参与本轮调优的真实复核者先独立判定。建议两人各自审阅并分别导出，再由第三人处理分歧。
- 填写本人真实标识（可用稳定别名）和具体理由；问题含糊、对象不明、依赖链缺失时选“需修订”，不硬造二分类标签。
- 明确代码分支可以证明“否”；局部未见功能不等于全项目不存在。核对条件、数量、否定、异常路径和跨文件关系。
- 本阶段判断“冻结快照证据能否回答问题”。全仓真实实现与实际 Agent 已读范围是不同范围；缺少读取轨迹时不宣称定位了原运行第一跳。

## 导出与后续

点击“导出复核 JSON”，保存到本包之外的单独文件（每个复核者独立文件）。不要覆盖冻结作者标签、基线报告或 manifest。

第一阶段标签与理由锁定之后，才展示模型交付答案、被拒草稿与校验记录，分别审查：事实准确、所问核心覆盖、引用真实性、拒答适当性。人工标签与模型评分器的分歧应单独裁定，不能用模型再投票冒充人工。

导出前未填写的标签为 null；测试中临时标识仅存在隔离内存分区，未保存为人工金标准。页面没有外部请求。

新语言和真实调用链的验收题要另建版本，人工审核后封存为 holdout，运行前不得用其反馈改提示词或阈值。这 30 题只用于校准当前已曝光数据的标签/问题质量，不估计新场景泛化。
