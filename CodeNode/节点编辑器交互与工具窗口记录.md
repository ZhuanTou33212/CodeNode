# 节点编辑器交互与工具窗口记录

更新时间：2026-07-14

## 已实现的画布操作

- `Shift+A`：在鼠标位置打开节点库；通用分类包含空白、基础、数值与常量，语言专用分类随 Java、PowerShell、Go 切换。
- 输出端口拖动：贝塞尔连线实时跟随鼠标，释放到输入端口后建立命名端口连接。
- 鼠标中键拖动：平移画布和网格。
- `Ctrl+鼠标右键`拖动：绘制红色切线路径，释放时删除相交连接。
- `Shift+D`：复制节点和端口定义。
- `Delete` / `X`：删除节点；`Ctrl+X`：删除并尝试重连第一组上下游。
- `H`：折叠节点；`M`：静音节点；`Home`：查看全部；`Alt+X`：清理未连接节点；`Shift+W`：快捷操作菜单。

## 端口协议

输入和输出端口已进入 `WorkflowModel`，每个端口具有稳定 ID、名称、数据类型和必需标记。边保存 `sourcePort` 与 `targetPort`；提交申请时使用真实端口生成 schema 3.0 的 `[nodeId, portId]` 引用。删除端口会同步删除引用它的边；一个普通输入端口只保留一条入边。

## 工具窗口

- 节点资源管理器提供端口表格和增删操作。
- 底部恢复代码审查标签，展示所选节点职责、端口、产物、状态和诊断。
- 节点资源管理器与输出/代码审查区均支持收起为窄边栏、浮动为可自由移动窗口，以及关闭浮动窗口后重新停靠到原位置。
- 滚动条、分隔线、弹出菜单、表格和工具窗口标题均使用 Visual Studio 风格低对比深色主题。
