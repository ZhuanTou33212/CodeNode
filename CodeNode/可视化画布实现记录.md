# CodeNode 可视化画布实现记录

## 本次制作

依据《CodeNode 项目执行方案》阶段 1 的界面要求，在插件资源目录加入了一个零依赖画布原型：

- 文件：`codenode/assets/node-canvas/canvas.html`
- 样式：`codenode/assets/node-canvas/canvas.css`
- 交互：`codenode/assets/node-canvas/canvas.js`
- 版本：`0.2.0+codex.20260713010000`

## 已实现

1. 网格工作区和右侧检查器。
2. 初始画布为空；点击“空白节点”只创建草稿，不预先生成端口。
3. 在检查器填写制作要求并点击“制作节点”后，才生成中文端口和节点结构。
4. 拖拽节点标题移动节点，`Delete` 删除选中节点及关联边。
5. 从输出端口拖到输入端口建立连线；同一输入端口只保留一条边。
6. 端口类型不匹配时拒绝连线并在检查器显示原因。
7. 滚轮缩放；中键或 `Shift`+拖拽平移；“适配视图”恢复默认视口。
8. 节点选中后在检查器显示名称、制作要求和状态。
9. 视觉改为灰色系，端口统一使用中文名称。

## 使用方式

在浏览器中打开 `codenode/assets/node-canvas/canvas.html`。这是阶段 1 的交互原型，不依赖 React、构建工具或网络服务；后续可以把同一数据模型迁移到 React Flow。

## 边界与后续

当前实现没有持久化、撤销/重做、循环检测、键盘无障碍导航、虚拟化渲染和 Codex 页面入口。制作按钮目前使用最小本地规则演示“按需生成”交互，不代表 Agent 已接入。

## 响应式窗口布局（2026-07-14）

- 检查器支持拖拽左边缘调整宽度，并可折叠为窄侧栏。
- 代码审查和制作请求分别使用可折叠区，减少长面板占用。
- 新增底部“运行结果”面板，可收起并保留工作区空间。
- 画布、检查器和运行结果使用 CSS Grid 的自适应尺寸；窗口变窄时自动进入画布 + 侧栏布局。
- 工具架保持横向滚动，避免小窗口下按钮重叠。

补充：代码审查已从检查器内部拆分为独立中间栏，形成“画布 → 代码审查 → 检查器”三栏结构；代码审查栏与检查器分别支持折叠和拖拽调整宽度。
