# 阶段 0：Codex 插件制作记录

## 目标

建立可安装的 Codex 插件骨架，并验证 Java 第一阶段所需的工具链、Skill 协议和最小示例工作流。

## 已制作内容

- `.codex-plugin/plugin.json`：插件清单、版本、入口说明和默认提示词。
- `skills/codenode-java/SKILL.md`：环境检查、示例生成、节点输入协议和安全边界。
- `scripts/check-java-env.ps1`：检查 Java、`javac`、Maven Wrapper、Git 和工作目录。
- `scripts/create-java-demo.ps1`：生成 `AddIntegers` Java 类、JUnit 5 测试和 `pom.xml`。
- `README.md`：插件用途、目录结构和本地检查命令。
- 个人 Codex 插件市场中的 `codenode` 条目及缓存版本标记。
