## 尚未解决或不足以证明完成

1. completionCheck 的 contains/equals 仅验证返回字符串，不能独立验证文件、测试或自然语言业务目标；模型可以自报所需文本。自然语言条件仍未被运行时验证。
2. “重新发起审批”按钮调用 retryResume，重发原始任务，并没有绑定原待审批调用的参数重签发。旧 Run 提前标记被取代，且 replacementRunId 与 sendChat 实际生成的 Run 标识不一致。已有恢复 UI 测试覆盖工作流恢复，不证明审批跨进程重签发链。
3. semantic grounding 以 10% 词面重叠判断 supported，不验证否定、数值、引用对应关系，不是语义事实核查。当前专项测试仅覆盖新配置解析与旧引用校验，未证明语义质量。
4. PII redact 只处理本轮 prompt 与最终正文。历史、工具数据、推理与流式分片没有全链路统一过滤；分片在最终脱敏前已发给 UI。现有纯函数测试不能证明端到端无泄漏。
5. 发布运行日志存在模型密钥解密失败，原模型配置应保留；不能用重建或删除用户配置掩盖问题。
6. 测试运行器的 Windows spawnSync 超时终止 shell 不证明其子进程树全部退出；现有正常路径测试不能证明挂起清理。

本报告不将绿色测试或字符串匹配称为完整语义验收。Windows 内核隔离、通用副作用补偿、买签名证书按用户要求不在范围内。
