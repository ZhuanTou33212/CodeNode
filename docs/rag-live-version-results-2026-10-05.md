# 最终答复前的实际文件版本核验

本轮补工具历史无法观察到的外部编辑。目标保持进行中，不将此项修复扩大为全部 RAG 问题完成。

## 证据身份

普通文本及 PDF/Office 索引证据的 sourceSha256 从同一次读取的原始字节计算，避免提取旧正文后再读取新文件生成哈希。每个块携带不可变版本，父级/相邻来源保留自身读取版本。

若异步向量或重排处理期间发生索引提交，检索不会把旧片段配上当前缓存的新哈希；整体缓存修订变化时返回 RAG_SNAPSHOT_CHANGED，需要重试。

## 核验链

最终引用位置/事实判定后，后台文件 worker 对实际使用的文件核验原始 SHA-256。已修改、删除、不可访问、无版本或越界链接均不能默认为 verified。

核验最多 32 文件，每文件最多 20 MiB、合计最多 64 MiB，有取消信号与 10 秒超时；worker 不可用时不在主线程进行同步降级。

路径必须是项目内相对路径；realpath 后再验证文件仍在项目真实根内，阻止父目录穿越和指向外部的 junction/symlink。读取前后比较 size、mtime、inode，读取期间不稳定返回明确错误。

版本核验在可能耗时的模型判定之后执行，不仅在其之前检查。报告带 checkedAt；这证明的是核验时刻的版本，不是持续锁住文件。核验后到界面交付之间仍存在无法完全消除的外部编辑窗口。

默认 warn 模式保留警示策略，明确配置 enforce 时阻断 stale/unknown 引用。没有将既有默认警示策略偷偷改为强阻断。

## 验证

- 读取与 RAG 原始字节身份。
- 相同大小与相同 mtime 的外部改写。
- 文件删除、无哈希、项目外 junction。
- 索引处理期间更新，禁止混合片段/版本。
- 真实 Agent 工具循环：模拟判定模型请求期间外部同-stat 写入，严格门禁在交付前检测 stale。
- 既有引用校验、输出契约、深读/文档和后台索引回归。

测试数据在本机临时目录生成，不发送至外部模型。模拟模型仅验证运行接线，不代表真实判定准确率。

## 尚未完成

独立人审、新的未见验收、稳定高召回和完整任务达成率、更多语言 AST/OCR/文档边界及任意规模性能等仍未完成。历史版本叙述需要明确版本出处，不能用当前路径引用冒充旧状态。
