# 真实语义、结构分块与深读证据修复

本轮继续完整 RAG 修复目标。所有 100 题实验都是已曝光的 v2 回归集，标签仍为 AI 作者标签，没有伪造人审或新的未见验收结果。

## 真实模型消融

同一冻结源码、70 个正样本，Top-K=6，检索字符预算 12000。以下首先是旧结构版本的对照，未使用查询改写或模型判定来混入纯检索结果。

| 配置 | 全部必要证据 Recall@6 | 暖查询 p50 | 首次查询（含建索引） |
| --- | ---: | ---: | ---: |
| BM25 | 45.71% | 1.51 ms | 0.22 s |
| 严格纯 Dense：multilingual-e5-small INT8 | 41.43% | 8.19 ms | 14.41 s |
| BM25 + E5 混合 | 38.57% | 7.92 ms | 14.08 s |
| 混合 + mMARCO 交叉编码器 | 32.86% | 3537.50 ms | 17.61 s |

重排器是真实神经网络，不是脚本打分或 LLM 替身。固定版本为 SugoLabs/mmarco-mMiniLMv2-L12-H384-v1，revision `6772eee1ea62dc82e1fcaaf3ed90c269fdcb1fcf`，ONNX INT8 约 118 MB。来源与文件 SHA-256 记录于 `.cache/rag-experiment/mmarco-reranker/manifest.json`。只下载 ONNX/JSON，不执行模型仓库 Python 代码，源码不发送到下载站。

[模型原始实现](https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1)与[ONNX 转换模型](https://huggingface.co/SugoLabs/mmarco-mMiniLMv2-L12-H384-v1)主要面向多语文本相关性，不代表一定适合代码。当前实验没有收益，故未设为默认。

## 查询与文档输入身份

[E5 模型说明](https://huggingface.co/intfloat/multilingual-e5-small)要求区分 `query:` 与 `passage:` 前缀。现在三个向量后端都显式标记 query/document 输入；前缀进入 SQLite 缓存身份，变更后不会复用不匹配的向量。

`pureVector=true` 只用于 `mode=vector`，必须有学习式嵌入和独立召回。纯 Dense 排序不混入词法分数或关系图；没有向量、只有哈希或只有词法预筛时明确失败，不能把降级结果算成纯 Dense。

## 结构与上下文修复

私有常量原先与较大的模块片段混在一起，阈值与配置字段容易漏召回。现在：

- 顶层私有常量是独立结构段。
- 多行静态对象与 Object.freeze 配置表按属性边界分块，保留父级声明及完整命名空间。
- 同一行多个属性、计算属性、spread 等不安全拆分情况回退完整变量段，避免丢行。
- 可补全同一已索引文件中的相邻原文，最多两个邻片段、行距默认 12，仍共享每结果 500 字符上下文与整体字符预算。
- 相邻片段独立引用真实行号，不伪装成父类声明，也不读取未索引文件或越过文件范围。

纯词法回归的完整证据 Recall@6：45.71% → 私有常量与邻文 48.57% → 配置属性分块 51.43%。一次保守英文单复数扩展使该指标回落到 48.57%，因此已撤回，没有部署负收益实验。

## 并发与缓存失效

同内容、同模型、同预算及取消作用域的在途文档嵌入共享计算；不同预算或信号不合并。内容/模型身份与文件失效代际防止旧请求的迟到结果污染新缓存；关闭后也不会迟到写回。缓存容量与显式的有界全量语义扫描容量匹配，避免扫描超出缓存容量时反复重算。

真实本机 Jina 探针：32 份合成代码、3 个同时查询。旧提交 `b74a2ce5d36f0660f6ca15cf08ddeb3d6894096f` 文档请求 3 次、计算 96 个向量、耗时约 705 ms；新缓存文档请求 1 次、计算 32 个向量、约 263 ms。这是单次小规模测量，不是大型项目 SLA。

## Agent 深读与最终判定

发现最终校验此前只消费 retrieve_context，遗漏 read_file 深读与 query_scalars 的精确数据。现已接入真实深读正文、读取范围及标量值。按最终回答实际引用范围选证据，减少无关文件正文挤爆校验预算。

深读正文保留于工具记录，模型投影不重复发送；源文件版本哈希保留供写操作前置校验。合法短否定与短数字值也作为实际事实，不再因任意长度阈值被丢弃。中途截断行有显式标记，不允许据其推断未读到的条件。

通用查找/搜索与 RAG 已统一嵌套业务 cache 目录规则：src/cache 可检索后继续搜索深读，根 cache 与 node_modules 仍排除。

## 重排协议与回退

重排服务必须覆盖请求的全部候选，重复索引、越界、空/非数字分数都会失败并保留原始 RRF。自定义客户端有超时及取消边界；不把部分返回当成成功重排。
