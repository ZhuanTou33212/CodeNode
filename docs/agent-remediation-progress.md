## 已有修复与证据

- 密钥：拒绝 Base64 写入回退和 basic_text 后端；解密/解析失败不重新初始化配置；使用临时文件原子替换；空模型列表不重新填充。
- model-store-security-test.cjs：模拟密钥环不可用、解密失败、配置损坏，验证原文件不会被覆盖。实际系统密钥环迁移与 UI 错误提示仍待验证。
- 网络：publicHttp.cjs 使用已校验 IP 的 lookup 连接，保留 Host/TLS 服务名；逐跳检查重定向；整体超时覆盖 DNS 和正文；限制下载字节数；支持主 Agent 取消。
- public-http-security-test.cjs：受控本地 HTTP 服务验证固定解析结果、私网重定向拒绝、正文超限、慢正文超时、取消。测试替换传输边界，生产代码没有允许私网的开关。真实 TLS 集成仍待验证。
- IPv6 公网策略目前保守拒绝 2001 地址段及转换地址，可能拒绝部分合法公网目的地；后续应使用经过测试的精确地址范围表完善兼容性。
