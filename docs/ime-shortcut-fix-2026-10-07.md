# 空格平移与输入法快捷键

用户报告搜狗输入法在记事本中可以用 Win + 空格切换，但 CodeNode 中不会弹出系统输入法列表。
排查时，CodeNode 从固定交付路径由 Explorer 启动，CodeNode、搜狗代理和 Windows 输入服务均未提升权限；输入服务运行正常。

隔离渲染测试发现，React Flow 默认的 `panActivationKeyCode="Space"` 会在未收到前置 Meta 按键事件时，对带 `metaKey` 的空格调用 `preventDefault()`，包括焦点位于对话输入框的情况。
此结果证明应用内部存在按键处理冲突，尚不能单独证明它就是系统输入法列表不弹出的原因。

工作台关闭 React Flow 默认的全局空格监听，工作台与矢量画布共用 `useSpacePan`：

- 只有未按修饰键、未进行输入法组合输入、焦点和事件目标均不在交互控件中的空格可以激活平移。
- Win／Ctrl／Alt／Shift + 空格及 IME 组合输入不被这套平移逻辑阻止。
- 失焦、进入输入控件、组合输入开始或按下修饰键时释放平移状态。
- 保留普通空格拖动、空格滚轮平移和中键平移。

`npm run test:ime-shortcut-ui` 在隔离 Electron 渲染器中验证两个主题下的快捷键放行、工作台及矢量画布平移、状态释放和主题切换后的会话／草稿／模型／侧栏保留。
这些合成事件测试不覆盖 Windows Shell、搜狗原生输入服务或真实键盘，系统列表仍需使用固定路径交付包人工复测。
