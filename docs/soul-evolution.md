# 随对话成长的人格

CodeNode 的初始人格与成长记录共同保存在 `E:\CodeNode\config\soul.md`。桌面与命令行的主代理每完成一轮成功对话，会将脱敏后的有限上下文写入此文件的成长标记区域，保留原有设定。开发运行、暂存打包和 `release/win-unpacked` 交付版均读写同一份 `config/soul.md`，不在 C 盘或 CodeNode 根目录另建人格文件。外部文件独立于交付包，覆盖交付版时会保留。回归测试通过 `CODENODE_SOUL_FILE` 隔离到临时文件。提示词仅注入人工设定与已形成的人格倾向，不注入成长样本和内部状态，也不重复注入人工设定。

每累计五轮新对话，使用当前模型进行一次最多 1400 输出 token、15 秒超时的人格反思。只保留五类长期倾向：表达习惯、性格倾向、协作方式、重视的原则、相处方式。每个变化需要两个不同轮次的用户原话证据。没有足够证据时维持原人格。成长状态保存在同一个 Markdown 文件里，最多保存十轮脱敏摘要，不保存工具输出或思考过程。

下一次对话会读取最新人格。人格只影响风格，当前用户指令仍优先。失败、取消、事实校验拒绝及子代理运行不学习；反思失败保留原人格，正常任务结果仍交付。文件使用短事务锁与原子写入，遇到损坏不覆盖。人工写在成长标记区域之外的内容会保留，并用于后续人格注入。

在全局或项目 `agent.properties` 中设置 `soul.evolution.enabled=false` 可以停用成长及其注入，原始人格仍有效。删除 `config/soul.md` 的成长标记区域可重置成长记录，保留原有设定。反思调用沿用模型队列、预算与费用记录，会产生少量额外模型费用。人格倾向是模型根据对话形成的描述，不能等同于真实意识。

验证：`npm run test:soul`。
