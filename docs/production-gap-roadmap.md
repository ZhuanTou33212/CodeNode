## 费用规则

`agent.max_cost_usd=0` 保持关闭；正数开启按配置单价计算的 Run 费用上限。主/子/压缩/意图调用与 embedding 在发起前预留；供应商未给有效用量时保留该请求预留上界。开启上限却没有实际候选模型的单价时拒绝请求。重排服务需要显式 `rag.rerank_max_cost_usd` 每请求上界，可明确配置本地免费服务为 0。

价格来自用户配置；供应商实际价格或用量超过估算时不能声称账单绝不会超额。系统会如实记录预算占用与计费未知，不将估算冒充账单。

含图片请求在费用硬上限开启时还须提供 `cost.image_input_tokens.<实际模型>`。短 URL、压缩文件大小和本地上下文粗估不能证明图片计费上界；缺少该上界则在发送前拒绝。失败流中的初始用量不被当成最终用量，仍保留输出预留；`total_tokens` 大于输入输出之和的差额按最高配置单价保守计入。
