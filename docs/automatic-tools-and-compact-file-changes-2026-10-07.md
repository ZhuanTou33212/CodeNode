# 普通工具自动执行与简洁文件变更

按用户要求，对话正文不再显示任务轨迹、推理展开区或原始工具调用列表。成功写入以“已编辑 N 个文件”显示，点击“查看变更”可查看文件列表及已记录的差异；纯读取和画布操作不冒充文件编辑。

## 执行策略

默认自动执行普通文件读写，以及创建、重命名、移动、连线等非删除画布编辑。用户已明确选择高风险仍需确认，因此 HIGH、删除类画布操作、工作树及未列明写工具保留现有审批。路径边界、只读能力、语法、版本冲突及资源租约继续生效。

默认值及自动范围集中在 `config/ui.agent.json`，项目设置使用 `.codenode/agent.properties` 的 `tools.confirm_writes`。设置 → 常规 → Agent 执行提供“普通工具自动执行”开关，昼夜共用，下次任务生效。

注册表和旧执行上下文确认方法共用绑定工具身份的策略，防止只关注册表而文件编辑仍弹窗。上下文 fork 继承模式；强制确认不会因普通自动模式跳过。

## 文件变更口径

- 成功文件工具按路径去重；同一文件多次修改仍只计一个文件。
- 部分成功的批量写入只取实际 `written` 列表，不从请求参数推断全部成功。
- 实时文件写入通知和校验检测到的路径保留在消息数据中，支持运行中展示及历史恢复。
- 未完成、失败、纯读取、纯画布调用不计文件；已知哈希未变化的写入不计内容编辑。
- 同文件多次修改展示各次已记录的差异，不把累计编辑行数冒充净变化。无差异记录时可打开文件。

内部调用与推理数据仍保留供审计/恢复；默认对话隐藏这些面板及成功来源徽标。失败、证据不足和简洁校验状态继续可见。
