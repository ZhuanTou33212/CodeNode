## 修复

- 统一 `citations.cjs` 解析方括号、反引号、单行/行区间、标准 Markdown 源码链接；位置校验、事实证据选择、证据历史和版本核验共用解析。

- Markdown 标题中的事实也参加校验。纯章节或引用标签可由模型判为非事实；有项目断言的标题不能一概跳过。

事实判定仍是概率性模型判断；位置正确和真实引句存在都不能单独证明逻辑蕴含。
