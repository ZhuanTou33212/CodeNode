## 本轮真实回归

所有数字相对 AI 作者标签，不是人审金标准准确率。原始 100 题结果不覆盖，后续实验均标为 exposed-regression。

| 阶段 | Oracle 可回答性一致率 | Oracle 正样本通过率 | Oracle unknown |
| --- | ---: | ---: | ---: |
| 原始判定器 | 46% | 28.57% | 14 |
| 最小核心事实与 JSON 修复 | 82% | 74.29% | 0 |
| 中性是非问题语义修复 | 83% | 75.71% | 0 |

实际检索原始一致率 37%；最小核心事实版本 61%；加入问题改写的另一组回归为 59%，unknown=3，完整证据 Recall@6 从 45.71% 升至 50%。检索指标的小幅改善没有带来稳定的整体判定改善，不能把它描述为全部问题已解决。

3 个失败分别为原问题片段引用错误和引句不匹配。事实计划字段现已纳入受控格式纠错，不能改成默认放行；最新代码尚未独立量化这一补丁的收益。
